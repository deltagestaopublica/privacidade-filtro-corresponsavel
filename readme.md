# Política de privacidade — Filtro de Corresponsável (Procuradoria)

Este repositório existe por um motivo só: **hospedar uma página**. A Chrome Web
Store exige uma URL pública de política de privacidade para qualquer extensão
que declare `host_permissions`, e o GitHub Pages só serve repositório público.

Publicado em
<https://deltagestaopublica.github.io/privacidade-filtro-corresponsavel/>
(branch `main`, raiz do repositório).

## O que NÃO está aqui

O código-fonte da extensão. Ele fica em
`deltagestaopublica/filtro-corresponsavel-procuradoria`, que é **privado** e
continua privado. Aqui só existe o texto da política — um `index.html` estático,
sem script, sem dado de cliente, sem nada que a Delta não queira que o mundo
leia.

## Ao mudar a extensão

Se uma versão nova passar a acessar outro host, a guardar alguma coisa no
navegador ou a mandar dado para fora, **esta página precisa mudar junto** —
a política é uma declaração de fato, não um texto de praxe, e o Google compara
os dois na revisão.
